## 🚀 Featured Project

### 🎧 Smart Headphone — Real-Time Language Translation

> **Final Year Project** combining embedded hardware, machine learning, and real-time audio processing.

A smart headphone system designed for **real-time language translation**, **fake voice detection**, and **audio recording**.

**Key Features**

- 🌐 Real-time **English ↔ Urdu** language translation
- 🗣️ Speech recognition and audio processing
- 🛡️ Machine-learning based **fake voice detection**
- 🎙️ Audio recording functionality
- 🍓 Built around **Raspberry Pi 4**
- 🔌 Integration of microphones, audio modules, and embedded hardware
